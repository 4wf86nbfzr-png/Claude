Disposition & Einsatzsteuerung — Demo zum Ansehen und Ausprobieren

Was Sie hier vor sich haben

Der HST Planer ist die Dispositionsplattform für das HERM Service Team: von der eingehenden Anfrage über die Personalplanung bis zum Abgleich der tatsächlich geleisteten Zeiten. Diese Datei zeigt ihn zweifach — in Bildschirmfotos der laufenden Anwendung und zum Selbst-Ausprobieren der Rechenkerne.

Wichtig: Die Werkzeuge auf den Reitern „Zeitrechner“, „Namensabgleich“, „E-Mail-Parser“, „Abgleich“, „Zuordnungsprüfung“ und „Rollen & Rechte“ sind keine Nachbauten. Sie führen denselben Code aus, den auch der Server benutzt — gebündelt aus src/lib/. Was hier herauskommt, kommt dort genauso heraus.
Leitstelle

Der Tag als Zeitachse: links die Kräfte mit Zustand und Qualifikation, rechts der Einsatzplan. Ein Name wird auf eine Schicht gezogen, geprüft wird beim Ablegen.

Rollen & Rechte

Neun Rollen, Standard DENY ALL. Eine Teamleitung sieht zum eigenen Einsatz Name, Funktion, Zeit, Ort und Qualifikation — Vertrag und Anschrift werden für sie gar nicht erst geladen.

HST Compliance

Verarbeitungsverzeichnis, TOM, Auftragsverarbeiter, Löschkonzept, Betroffenenanfragen, Vorfälle, DSFA und ein Sicherheitscheck — ohne Erfüllungsquote und ohne die Behauptung, DSGVO-konform zu sein.

Abgleich

Stundenzettel als Excel oder CSV einlesen, Mitarbeiter zuordnen, jede Abweichung zeigen, von Hand korrigieren und beim Abschluss in die Zeiterfassung übernehmen.

Anfragen

Website-Formular, E-Mail-Parser und telefonische Erfassung. Eine eingehende Anfrage ist nie eine Buchung, sondern immer ein Vorgang zur Prüfung.

Mitarbeiter-App

Mobile Ansicht: heutige Einsätze, annehmen oder ablehnen, Verfügbarkeit melden, Nachweise hochladen, Nachricht an die Disposition.

Was hier nicht geht

Anmeldung, Datenbank, Datei-Uploads, E-Mail-Versand und der zweite Faktor lassen sich in einer einzelnen HTML-Datei nicht ehrlich zeigen — sie brauchen den Server. Der zweite Faktor rechnet zudem mit Funktionen, die es im Browser nicht gibt; er ist gegen die Prüfwerte aus Anhang B des RFC 6238 getestet. Wie Sie den Server in wenigen Minuten starten, steht unter Selbst starten.

Was dieses System nicht behauptet

Es behauptet nicht, DSGVO-konform zu sein. Es unterscheidet zwischen technisch umgesetzt — das lässt sich feststellen — und rechtlich geprüft — das kann nur ein Mensch. Es trägt keine Rechtsgrundlage von sich aus ein, und es bewertet nicht, ob ein Datenschutzvorfall meldepflichtig ist. Eine Erfüllungsquote gibt es nicht: „98 % DSGVO-konform“ wäre eine Zahl ohne Gegenstand.

Die Anwendung in Bildern

Alle Aufnahmen stammen aus der laufenden Anwendung mit den Testdaten aus npm run seed — keine Entwürfe. Ein Klick vergrößert.

Zeitrechner

Einsätze laufen regelmäßig über Mitternacht. 18:00 bis 02:00 sind acht Stunden — nicht minus sechzehn. Genau daran scheitern Tabellen in der Praxis, deshalb rechnet der Planer in Minuten ab Schichtbeginn. Probieren Sie es aus.

Dauer einer Schicht

Der Leser versteht auch 17.00, 1700, 17, 17:00 Uhr und Excel-Uhrzeiten als Tagesbruchteil (0,75 = 18:00).

Abweichung zwischen Soll und Ist

Die Differenz bleibt im Fenster von zwölf Stunden. „Geplant 23:55, gekommen 00:10“ sind 15 Minuten zu spät — nicht 23 Stunden zu früh.

Deutsche Datumsangaben

Ohne Jahresangabe wird das nächste Vorkommen genommen — so, wie es in einer E-Mail gemeint ist. Zahlen über 20000 gelten als Excel-Seriennummer.

Namensabgleich

In Partner-Stundenzetteln steht mal „Max Mustermann“, mal „Mustermann, Max“, mal „MUSTERMANN Max“ — und gelegentlich ein Tippfehler. Der Planer ordnet zu, ohne zu raten: ab einer Trefferquote von 92 % automatisch, aber nur, wenn kein zweiter Kandidat fast gleich gut passt.

Gestaltung

Eine Dispositionsoberfläche lebt von Dichte und Ruhe, nicht von Farbe. Fläche und Schrift sind neutral, Farbe trägt ausschließlich Bedeutung. Der Akzent ist das Violett aus dem HST-Logo und erscheint sparsam: aktive Navigation, primäre Schaltfläche, Fokusring.

Statusfarben

Grün = bestätigt, besetzt, erledigt · Gelb = offen, braucht Aufmerksamkeit · Rot = Problem, unbesetzt, Fehler · Blau = Information, Planung

Die vollständige Anwendung selbst starten

Für Anmeldung, Rollen, Datenbank, Uploads und E-Mail brauchen Sie den Server. Mit den Testdaten ist er in wenigen Minuten einsatzbereit.

Voraussetzungen
Node.js 20 oder neuer und PostgreSQL 14 oder neuer. Sonst nichts.
Einrichten 
cd hst-planer
npm install
cp .env.example .env
# In der .env DATABASE_URL setzen und ein Geheimnis erzeugen:
#   openssl rand -base64 48   →  AUTH_SECRET
Datenbank und Testdaten 
npx prisma migrate deploy
npm run seed
Starten 
npm run dev        # http://localhost:3000

Was Sie als Erstes ausprobieren sollten

  1. Abgleich durchspielen. Abgleiche → Datei hochladen, dann beispiele/stundenzettel-beispiel.xlsx wählen. Die Datei enthält absichtlich einen gedrehten Namen, einen Tippfehler, eine Zeitabweichung, eine unbekannte Person und eine Dublette. Spalten bestätigen, Abgleich starten, die roten Zeilen von Hand klären, abschließen — die Zeiten stehen danach in der Zeiterfassung.
  2. Lücke schließen. Disposition öffnen, bei einer Position auf „Personal suchen“ klicken. Der Planer sortiert nach Eignung und warnt bei Urlaub, Überschneidung oder fehlendem Nachweis — blockiert aber nur, wo es fachlich nötig ist.
  3. Rollen prüfen. Als max.mustermann@example.org anmelden. Die Navigation schrumpft auf den eigenen Bereich, und /events leitet auf einen verständlichen Hinweis um statt auf eine Fehlerseite.
  4. Anfrage übernehmen. Anfragen öffnen, eine Anfrage in ein Event überführen — Position und Personalbedarf werden gleich mit angelegt.
  5. Einsatzplan drucken. Auf einer Event-Seite „Einsatzplan“ öffnen und drucken. Interne Notizen stehen bewusst nicht darauf.

npm test                  # 148 Tests, davon mehrere gegen eine echte Datenbank
